DEVTRACK
========
A lightweight personal developer study dashboard.

How to use:
1. Open index.html in Chrome/Edge.
2. Your completed days are saved automatically in your browser's localStorage.
3. The dashboard selects today's roadmap item automatically.
4. To host it, upload index.html to any static host such as GitHub Pages, Netlify or Vercel.

The roadmap data comes from the developer study timetable created for this plan.
