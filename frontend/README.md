# DevTrack Frontend Redesign

This package contains a redesigned `frontend/index.html` and `frontend/api.js` for the existing DevTrack backend.

## Deploy
Use the same Static Site setup:
- Repository: chyber-nana/DevTrack
- Publish Directory: frontend
- Build Command: leave blank

The API client defaults to:
https://devtrack-w6u3.onrender.com/api

## Included
- Redesigned dashboard/workspace UI
- Responsive mobile drawer
- Calendar
- Day-by-day roadmap with missed/today/upcoming states
- Daily notes
- Progress charts
- Achievements
- Notifications/reminders
- Projects with progress + GitHub/demo links
- Profile/settings
- Change password
- Forgot/reset password
- Admin dashboard (admin role only)
- Light/dark theme toggle
- Loading overlays and toast notifications

The frontend expects the existing DevTrack backend routes and authentication system.

- Interactive roadmap flowchart with animated week nodes, connectors, and expandable day sessions
